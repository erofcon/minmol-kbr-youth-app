# Minmol-kbr - Система бронирования помещений

Проект представляет собой веб-приложение для бронирования помещений молодежных центров Кабардино-Балкарской Республики,
интегрированное с Telegram Mini Apps.

![Пример главной старницы](docs/img.jpg)

## 🏗️ Структура проекта

Проект состоит из двух основных частей:

### Backend (Django REST API)

- **Фреймворк**: Django 5.2.7 + Django REST Framework
- **База данных**: SQLite (в разработке), PostgreSQL (в production)
- **Документация API**: DRF Spectacular (Swagger/Redoc)

### Frontend (Vue.js SPA)

- **Фреймворк**: Vue 3.5.22 + TypeScript
- **Стили**: Tailwind CSS 4.1.14
- **Навигация**: Vue Router 4.5.1
- **Состояние**: Pinia 3.0.3
- **Сборка**: Vite 7.1.9

## 🚀 Основные возможности

### Для пользователей:

- 📅 Бронирование помещений с выбором даты и времени
- 📱 Нативная интеграция с Telegram Mini Apps
- 🔍 Просмотр доступных помещений с фильтрацией по районам
- 📋 Подача заявок на бронирование с заполнением формы
- 📊 Просмотр мероприятий и молодежных организаций

### Для администраторов:

- 👥 Управление пользователями и правами доступа
- 🏢 Управление помещениями и их характеристиками
- 📋 Рассмотрение заявок на бронирование
- 🏛️ Управление молодежными центрами и районами

## 🎨 Особенности интерфейса

- Адаптивный дизайн для мобильных устройств
- Поддержка свайпов для навигации "назад"
- Интеграция с Telegram WebApp для нативного UX
- Темная/светлая тема в зависимости от настроек Telegram
- Скелетон-загрузчики для улучшения UX

## 🔐 Безопасность

- Валидация данных на стороне клиента и сервера
- Ограничение прав доступа для разных ролей пользователей
- Валидация временных слотов для предотвращения конфликтов бронирований
- Защита от переполнения полей ввода

## 📱 Telegram Integration

Приложение поддерживает:

- Нативную навигацию через кнопку "Назад"
- Автоматическое определение цветовой схемы
- Получение данных пользователя из Telegram
